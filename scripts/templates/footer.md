## Contributing

Know a paper that belongs here, or spotted a wrong link? Contributions are very welcome.

- **Quickest:** open an issue using the [**Add a paper**](../../issues/new?template=add-paper.yml) template.
- **Pull request:** add a row to [`data/papers.csv`](data/papers.csv) and run `python scripts/build_readme.py`. Never edit this README by hand: it is generated from the CSV.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the column definitions and inclusion rules.
